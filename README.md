# Brisa

O clima, em outra perspectiva. Um observatório pessoal com mapa interativo, previsão, comparação de cidades, contexto histórico ERA5 e cartões PNG para compartilhar.

Aplicativo Next.js 16 · TypeScript · Open-Meteo · MapLibre · Gemini opcional.

Veja o README para desenvolvimento, fontes de dados, período histórico e configuração. O modelo atual é o Gemini 3.8 Flash; conecte a chave do AI Studio no aplicativo ou configure GEMINI_API_KEY em uma implantação privada.
